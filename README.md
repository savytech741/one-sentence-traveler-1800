One sentence, 191 characters, explaining the modern internet to a traveler from 1800 using only words and ideas from their own time — thin wires, a printing press that never sleeps, letters, pictures, and songs, carried quicker than a horse.

## Run it

```sh
node main.ts
```

It prints the entry sentence and its character count, and exits non-zero if the sentence ever exceeds the 200-character limit.
